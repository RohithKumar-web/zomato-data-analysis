# 🍽️ Zomato Data Analysis Project

## 📌 Project Overview
This project focuses on analyzing Zomato restaurant data to uncover valuable business insights related to customer preferences, restaurant performance, pricing trends, and geographical distribution. The objective is to transform raw data into actionable insights using data analytics techniques and interactive dashboards.

## 🎯 Business Objectives
- Understand customer dining preferences.
- Identify top-performing restaurants and locations.
- Analyze rating and pricing patterns.
- Discover factors influencing restaurant popularity.
- Provide data-driven recommendations for business growth.

- Online Delivery Insights

- Compared restaurant performance across different price ranges.
